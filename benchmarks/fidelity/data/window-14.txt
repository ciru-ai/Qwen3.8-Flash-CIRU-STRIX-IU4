Add getter methods for title bar controls in FoldableContainer

From 58b2ef7b362e8d8410e312801535455cbb265251 Mon Sep 17 00:00:00 2001
From: Voyend <voyend@outlook.com>
Date: Fri, 22 May 2026 14:07:45 +0300
Subject: [PATCH] Add get_title_bar_control and get_title_bar_control_count to
 FoldableContainer

Exposes the internal title_controls list via two new methods:
- get_title_bar_control_count() returns the number of controls
  currently added to the title bar.
- get_title_bar_control(index) returns the control at the given index.

Previously there was no way to query which controls had already been
added to the title bar, making it impossible to avoid duplicates when
calling add_title_bar_control() from external code.
